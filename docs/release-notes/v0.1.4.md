Everything since v0.1.3 is a change the laptop asked for.

## The play screen

The bar number used to be the biggest thing on it, and is close to the least
important for the way this band will use it. It stays — losing your place is
exactly when you want it — at a tenth of the height, in the corner.

The **visual metronome takes the middle** and is now the largest element, with
a faint ring on the live beat so it reads as movement from a distance rather
than a change of colour, and the downbeat outlined even when unlit so the
start of a bar is visible before it arrives. The dots size themselves to the
time signature, so 7/8 fits the width 4/4 does.

**Song title and artist are large**, in the shape of the NEXT block.

## Keys

- **Up and down do nothing while playing.** They used to move a selection that
  is not on screen during a song, so the next press of space started
  somewhere unexpected. `N` is the deliberate way to move on mid-song.
- **ESC never quits.** It leaves fullscreen, and in edit mode backs out one
  screen per press. A key that close to the transport should not be able to
  end the show.

## Fixed

- **`btui` plays audio.** It took a `--device` argument, read the file, and
  never opened a device. The title bar said "simulated transport", which is
  not good enough.
- **A device that disappears is noticed.** Pulling the USB cable used to do
  nothing at all: the playhead froze and the program sat there until Ctrl-C.
  The detection asked PortAudio whether the stream had errored; WASAPI reports
  no error for an unplugged interface — the callbacks simply stop. Their
  absence is the signal, and both `btplay` and `btui` watch for it now.
- **Demo stems are two minutes**, not eight seconds. A machine that drops a
  buffer three times in ten minutes reads zero xruns over a ten-second clip,
  so the old demo could not measure the thing it was being used to measure.
  `--seconds` chooses otherwise.
- **The editor's save button is disabled, with the reason**, when there is
  nowhere to save — rather than appearing to work on the built-in demo set and
  losing the edit on exit.

## Still not done

No waveform alignment, no MIDI or footswitch, no routing editor in the UI.
Dropout behaviour across buffer sizes is still unmeasured. macOS and Linux
build and pass their tests, and nobody has run them.
