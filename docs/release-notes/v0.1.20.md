A readable segue marker, and a tested answer about tempo precision.

## The segue marker in the set list

It was drawn with a curved arrow the stage font does not carry, so it came out
as the missing-glyph box — which reads as an error rather than as information.
It is a plain down arrow now.

## Tempo precision

A song's BPM is used exactly as entered. The three screens round it for
display — the set list to a whole number, the playing screen to one decimal,
the editor to two — because three decimal places across a dark room is noise.
None of that reaches the click.

It matters more than it looks. A backing track at 138.78 BPM played against a
click rounded to 138.8 is **62 ms** out by beat 1000, about a seventh of a
beat; rounded to 139 it is **684 ms** out, a beat and a half.

Now tested rather than assumed: `test_a_fractional_bpm_is_honoured_exactly`
checks that beat 1000 lands where 138.78 puts it and measurably not where
138.8 or 139 would, and a round-trip test checks the digits survive a save —
the file says `138.78`, not `138.78000000000001`.
