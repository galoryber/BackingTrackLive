Packaging fix for [v0.1.0](https://github.com/galoryber/BackingTrackLive/releases/tag/v0.1.0),
whose archives contained only `btrender` while the notes described four tools
and a stage UI. Same code, complete package.

## What is in the archive now

| | |
|---|---|
| `btui` | the stage UI — play mode and the set list / song editors (Windows) |
| `btplay` | plays a set list through a real audio device |
| `btrender` | renders a set list offline to WAV |
| `btcheck` | finds everything wrong with a set list in one pass |
| `docs/` | including `gig-laptop.md`, the runbook for the machine that plays the show |
| `examples/setlist/` | a runnable example |

The release job now verifies the package contains its own tools before
uploading, rather than trusting a list of filenames to stay in step with the
build.

## Everything else

Unchanged from v0.1.0 — see [those notes](https://github.com/galoryber/BackingTrackLive/releases/tag/v0.1.0)
for what works and, more importantly, what does not: ASIO is absent from these
binaries, dropout behaviour on real hardware is unmeasured, hot-unplug is
unverified, there is no waveform alignment and no footswitch, and the macOS
and Linux builds have never been run by anyone.
