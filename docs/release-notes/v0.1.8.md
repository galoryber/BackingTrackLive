Aligning a stem no longer means leaving the editor to find out whether you got
it right.

## Audition while you edit

The song editor has **play** and **stop**, and every edit the engine renders
from — tempo, count-in, length, gain, nudge, bus, mute — takes effect without
restarting the song. Nudge a stem while it plays and you hear the result from
where you already are, not from the top.

Checking alignment previously meant leaving edit mode, listening, coming back,
changing a number, and leaving again. The nudge and the ear belong on the same
screen.

There is a brief silence at the moment of a change, while the swap waits for
in-flight audio to finish with the old version. It is audible as a blip when
you nudge during playback. The alternative is tearing the audio, which is
worse, and the quiet version of this costs machinery that is not worth
building until the blip proves to be a nuisance.

## No more terminal window

The UI built as a console application, so double-clicking it opened a black
terminal alongside the program and left it there for the whole show. It is now
a windowed application. Typing its name in a terminal still works and still
prints, because it borrows the console it was launched from when there is one.

## Opening another set list

Moved to edit mode, where set-list-level work lives, and now actually wired —
in v0.1.7 the key did nothing at all. The stage screen should not carry a
control that throws the show away.
