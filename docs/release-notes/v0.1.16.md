**Naming a new set list froze every button on the start screen.** v0.1.15
should be skipped.

## The freeze

The name prompt took keyboard focus on every frame rather than on the frame it
appeared. That forces ImGui's active item back to the text box continuously,
and a button has to hold the active item from press through release — so for
as long as the prompt was up, nothing on the screen worked. Not just *Create*:
*Cancel* too, and opening an existing set list, and everything else.

Focus is taken once now.

The set list scan was also running every frame. It enumerates a directory, and
on a OneDrive-backed Documents folder those entries can be cloud placeholders
whose enumeration goes to the network — sixty times a second is its own way to
make a window stop responding. It now runs when the start screen appears and
when a set list is closed.

## Polish

**Tuning on the set list** has a right-aligned column of its own. It was
positioned relative to the tempo's width, so a two-digit tempo pushed it
somewhere different from a three-digit one.

**The next song's tuning** sits beside the next song's title, smaller. In the
opposite corner it read as the tuning of what is playing now, which is the one
thing it must never be mistaken for.
